# Visual assets

Folder: `docs/assets/`

All public-facing images are **concept / product art** (dark navy, amber accents).  
They deliberately **do not** include live lab data: no hostnames, LAN IPs, home paths, usernames, raw API JSON, or real Grafana metrics.

## Privacy rule

- Do **not** commit live UI screenshots, `/healthz` dumps, provider JSON, Grafana, or terminal output that shows lab topology.
- Prefer concept art in the same aesthetic as the hero image.
- Product map HTML may only use generic product names (no LAN, no usernames).
